# GEI Academy — YallToo

Genesis Engineered Interpretations educational application.

## V1.0 Clean Application Shell

This milestone establishes the static, mobile-first application frame only.

- Maximum frame width: 430px
- Height: 100dvh
- Responsive target: approximately 320px and up
- Safe-area aware
- No horizontal scrolling
- No runtime navigation yet
- No splash controller yet
- Static HTML/CSS only

The project is intentionally built in phases. Later systems must not be added until the current milestone has passed its verification gate.
