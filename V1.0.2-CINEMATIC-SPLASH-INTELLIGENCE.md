# GEI Dam Academy v1.0.2 — Cinematic Splash Intelligence

This milestone adds state-aware splash behavior without changing the Dashboard, Start, Portfolio, or Support screen architecture.

## Splash intelligence
- First visit: full cinematic entry sequence.
- Fast refresh within 90 seconds: rapid handoff to the app.
- Returning within 30 minutes: shortened re-entry experience.
- Re-entry after 30 minutes: medium cinematic sequence.
- Asset memory prevents immediate repetition.
- Motion memory prevents immediate repetition.
- State is persisted in `gei_splash_state_v2`.
- Enter, Skip, keyboard Enter/Space/Escape all provide immediate handoff.
- Reduced-motion preferences are respected.
