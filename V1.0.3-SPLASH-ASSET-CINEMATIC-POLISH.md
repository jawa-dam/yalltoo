# GEI Dam Academy v1.0.3 — Splash Asset & Cinematic Polish

This polish pass expands the cinematic splash from the two-image pool used in v1.0.2 to the larger Genesis Engineered asset pool supplied in the project source.

## Included
- Expanded splash asset rotation using the supplied Genesis Engineered image pool.
- Preserves v1.0.2 visit-aware timing: first, fast, returning, and re-entry modes.
- Preserves previous-asset avoidance across visits.
- Preserves previous-motion avoidance across visits.
- Keeps the mobile-safe 430px / 100dvh frame foundation.
- Keeps Enter, Skip, and keyboard handoff controls.
- Keeps reduced-motion support.
- Uses the cinematic hero entrance separately from the persistent motion loop so the reveal and looping effect do not fight each other.

## Source alignment
The asset pool and motion families are derived from the supplied Genesis Engineered portal source, which contains a large random hero-image list and a 24-effect motion pool.
