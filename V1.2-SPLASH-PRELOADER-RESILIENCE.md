# GEI Dam Academy V1.2 — Splash Preloader & Resilience

V1.2 strengthens the V1.1 splash runtime with explicit preloader behavior and resilient image handoff.

## Goals
- Preload the selected cinematic hero before the reveal completes.
- Show a lightweight loading state instead of a blank hero.
- Detect image load success and failure deterministically.
- Fall back to the YallToo mascot when a selected asset fails.
- Avoid duplicate load work for the same URL during one presentation.
- Keep first / quick / returning / re-entry timing intelligence intact.
- Keep the 430px / `100dvh` mobile frame intact.
- Keep Enter / Skip / keyboard handoff intact.
- Keep reduced-motion behavior intact.

## Runtime contract
The splash remains a single-page runtime inside `index.html`. V1.2 adds resilience around asset preparation without restructuring the Dashboard, Start, Portfolio, or Support screens.
