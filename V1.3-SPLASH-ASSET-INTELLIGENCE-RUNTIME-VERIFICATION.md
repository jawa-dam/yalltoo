# GEI Dam Academy V1.3 — Splash Asset Intelligence & Runtime Verification

V1.3 extends the V1.2 resilient splash runtime with explicit asset diagnostics, cache-aware asset selection, runtime verification, and a lightweight diagnostics surface.

## Goals
- Track which splash asset was selected and whether it loaded, failed, or timed out.
- Prefer a recently successful asset on the next presentation while preserving rotation.
- Record per-asset health in localStorage with bounded metadata.
- Detect the fallback mascot as a known healthy recovery path.
- Verify that the selected hero is actually rendered with usable intrinsic dimensions before reveal.
- Expose a non-blocking diagnostic badge during development/runtime inspection.
- Preserve V1.2 loading, timeout, fallback, keyboard handoff, reduced-motion handling, and timing intelligence.
- Preserve the 430px / `100dvh` mobile frame and the Dashboard, Start, Portfolio, and Support screens.

## Runtime contract
V1.3 remains a single-page runtime inside `index.html`. Asset intelligence is isolated to splash preparation and verification. No Dashboard, Start, Portfolio, or Support layout is restructured.

## Verification states
`selected -> preloading -> verified -> revealed`

Failure path:
`selected -> preloading -> failed/timeout -> fallback preload -> fallback verified -> revealed`

Diagnostics are informational only and must never block user entry.
