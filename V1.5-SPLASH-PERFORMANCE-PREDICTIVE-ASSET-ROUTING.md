# V1.5 — Splash Performance & Predictive Asset Routing

## Objective

Optimize the Genesis Engineered cinematic splash by using local runtime history and available browser network/device hints to predict an appropriate asset-routing and presentation strategy before loading the selected hero.

## Included

- Adds bounded local performance memory under `gei_splash_performance_v1`.
- Maintains a per-asset exponential moving average (EMA) for observed load time.
- Scores assets using recent health state plus observed performance history.
- Routes future splash selections toward assets with stronger recent health/performance signals while preserving rotation.
- Detects browser network hints (`effectiveType`, `saveData`) and basic device capability hints.
- Applies conservative preload budgets on constrained connections/devices.
- Uses predictive display timing based on prior load speed, network tier, and splash mode.
- Records predictive route decisions in existing local V1.4 telemetry.
- Preserves V1.3 health verification, V1.4 telemetry, Adam fallback, safe entry, keyboard handoff, reduced-motion support, and the 430px / `100dvh` mobile frame.
- No external analytics service is introduced.

## Runtime storage

`gei_splash_performance_v1` is local-only and bounded. It stores aggregate routing state and a capped list of recent per-asset observations.

## Safety / resilience

Prediction never bypasses image verification. A selected asset must still load successfully and have non-zero intrinsic dimensions before it is revealed. Failure or timeout falls back to Adam and then to safe entry.
