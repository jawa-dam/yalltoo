# V1.6 — Splash Random Image Rotation Engine

## Objective

Expand the GEI cinematic splash from a limited asset set into a canonical rotating image pool using the 60 user-supplied YallToo / Genesis Engineered image URLs.

## Runtime behavior

- Selects a splash image automatically on every full page load.
- Uses persistent local history so the same image is not selected twice in a row.
- Maintains a bounded recent-asset window to improve visual variety across refreshes.
- Preserves V1.3 asset-health verification and removes recently failed assets from the immediate candidate set when alternatives exist.
- Preserves V1.4 local telemetry and V1.5 local performance routing.
- Preloads the chosen asset before reveal.
- Keeps the YallToo animated mascot as the known-good fallback.
- Preserves the fixed 10-second automatic splash entry from V1.5.
- ENTER, SKIP, and keyboard handoff remain immediate.
- Preserves reduced-motion support and the 430px / `100dvh` mobile frame.

## Rotation state

The rotation engine uses local-only storage. It records the last selected asset and a bounded recent history so page refreshes can produce a different image without requiring manual image swapping.

## Safety / resilience

Random selection never bypasses verification. A selected image must successfully preload and report usable intrinsic dimensions before it is revealed. Failed or timed-out images fall back to Adam and then safe entry.

## Asset pool

The production pool contains the 60 image URLs supplied for this milestone by the project owner.

## Non-goals

- No external analytics service.
- No server-side session requirement.
- No manual per-refresh image selection.
- No changes to Dashboard, Start, Portfolio, or Support architecture.
